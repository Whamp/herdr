# Remote link externalization test contract

This matrix maps the remote-link behavior families to their highest authoritative maintained test seam. A higher seam proves routing and user-visible coordination. A lower seam owns deterministic policy or operating-system facts so socket tests do not repeat them.

## Protocol evidence

- The latest released tag, `v0.7.3`, has `PROTOCOL_VERSION = 16` in `src/protocol/wire.rs`.
- This implementation has `PROTOCOL_VERSION = 17`. The external-open wire change therefore retains the existing single unreleased bump and must not bump to 18.
- `tests/support/mod.rs` sets the manual socket fixture `CURRENT_PROTOCOL` to 17.
- `src/protocol/wire.rs::client_hello_roundtrip_includes_full_app_external_open_policy` and `terminal_connection_hello_roundtrip_omits_external_open_policy` own the full-app hello policy and attachment identity round trip and their omission from terminal connection hellos.
- `src/protocol/wire.rs::external_open_client_message_wire_tags_append_after_protocol_16_order`, `external_open_client_messages_roundtrip`, `external_open_policy_mutation_messages_roundtrip_with_stable_order`, `external_open_closed_value_wire_order_is_stable`, and `external_open_server_messages_roundtrip_in_stable_order` own tag order and round trips for every public external-open message and closed value.
- Compatibility remains exact-version through `src/protocol/wire.rs::version_older_client_rejected` and `version_newer_client_rejected`. There is no feature negotiation or mixed-version fallback.

## Layering rule

The socket suite is authoritative for source ownership, exact-client delivery, deadline linearization, commit authority, and per-client presentation. `src/external_open.rs` is authoritative for URL facts; `src/remote/forwarding/registry.rs` and broker tests are authoritative for mapping policy; the structured worker is authoritative for SSH argv and process control; and the real OpenSSH harness is authoritative for listener behavior. New end-to-end tests should not duplicate those lower seams unless the cross-layer integration itself changes.
